Adaptive VR Exposure Therapy — Acrophobia & Claustrophobia
A Unity-based Virtual Reality Exposure Therapy (VRET) system targeting two common phobias: acrophobia (fear of heights) and claustrophobia (fear of enclosed spaces), built for the Meta Quest headset.
The system includes three scenes: a VR main menu with ray-interactor controller navigation, a rooftop height-exposure environment where users gradually increase elevation via controller input, and a sci-fi corridor whose walls dynamically narrow as the user walks forward.
Exposure intensity is user-controlled and paced gradually, reflecting established principles from cognitive behavioral therapy. Built with Unity 2022 and the XR Interaction Toolkit.
Tech stack: Unity 2022 · C# · XR Interaction Toolkit · Meta Quest · Blender
Planned extensions: heart-rate adaptive exposure via Apple Watch, therapist web dashboard (WebSocket + JSON).
